The plugin lets the Cursor agent read those reports and the fix context, through a hosted MCP server that signs in with OAuth (no keys to paste).

Where things stand:
- The plugin bundle is in packages/cursor-plugin: plugin.json, mcp.json, a safety rule, skills and commands. The hosted server is https://kensaur.us/mushi-mushi/hosted-mcp/
