`mushi runner compare` shows what your CI costs and how fast it runs, per repo: GitHub-hosted versus your own machines, included minutes per GitHub account, speed factors, what-ifs and advice (ADR 0037). Read-only; money is always marked as an estimate. On WSL2, `mushi runner heartbeat` now also sends a hash of the VM's boot id so distros on one PC count as one machine for electricity.
