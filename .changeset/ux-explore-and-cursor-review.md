`mushi-ux explore` lets a model (the Cursor CLI, Grok by default) use the signed-in app like a careless user in the audit's read-only browser, and files only errors that happen again when its steps are replayed without the model (ADR 0046). `mushi-ux audit --review cursor` and `--checker-via cursor` review screenshots through the Cursor CLI in read-only ask mode.
