Add the `vibe` preset: `MUSHI_FEATURES=vibe` (stdio) or `?features=vibe` (hosted) lists only the 12 tools of the reported-bug loop: recent and searched reports, report detail, fix context, mark fixed, reply to the reporter, file a report, setup diagnosis, `use_mushi` and the docs tools. Chat connectors such as Lovable, and clients that slow down with many tools, get a short list; `vibe` combines with groups (`vibe,qa`), and the default and `all` surfaces are unchanged.
