New tools `preview_ci_cost_fix_rollout`, `apply_ci_cost_fix_rollout` and `get_ci_cost_fix_bundle`: preview every CI cost fix Mushi can open across your apps, grouped per repo with the estimated saving, then open them as one draft pull request per repo, so each repo runs CI once for all its fixes. Refused fixes are listed, never dropped.
