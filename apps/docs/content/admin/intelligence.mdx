# Weekly insights

**Route:** `/dashboard?view=insights` (**Home → Weekly insights**). The old `/intelligence`
link redirects there. It was called Intelligence reports before October 2026.

Mushi Mushi writes a **weekly bug digest** for each app: an AI-written summary of the
week's bug trends, fix velocity and areas of concern, with two or three recommendations.
You read it in the console, print it to PDF, and can have it posted to Slack.

The view has three tabs: **Summary**, **Reports** and **Jobs**.

---

## What's in a report

The digest is written from the week's data:

- reports by category, severity and component
- fix attempts and how they ended
- the grader's weekly scores (see [Triage grading](/admin/judge))
- anonymised benchmarks from other projects, only if you opted in and enough projects
  contribute (see below)

The AI writes the summary, so its exact sections vary from week to week.

---

## Schedule and delivery

The `intelligence-report` function runs every **Monday at 06:00 UTC**. Each report is
stored as HTML and listed on the **Reports** tab.

| Channel | How it works |
| ------- | ------------ |
| **In the console** | **Reports** lists every stored digest. Open one to read it |
| **PDF** | Open a report and use the browser's print dialog to save it as PDF |
| **Slack** | Posted when the project has a Slack webhook set |

Mushi Mushi does not email the digest.

---

## Generating on demand

Click **Generate this week** to run the digest for the current app now. The **Jobs** tab
shows each generation job with its status and error, and you can cancel a running job.
Generation is limited to 20 per hour. A run is skipped, with a reason, when no usable AI
key is configured.

---

## Cross-customer benchmarks

Benchmarks are opt-in, from the card on the **Summary** tab. When you opt in, the digest
can compare your app with anonymised aggregates from other Mushi Mushi projects. A
comparison is only shown when at least 5 projects contribute to it (k-anonymity).

---

## Jobs tab

Besides generation jobs, the **Jobs** tab lists pending library modernization findings,
which you can dispatch as a fix or dismiss.
