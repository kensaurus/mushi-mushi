# Jira Cloud plugin

Opens a Jira issue for each Mushi bug report and keeps it in step as the
report moves to fixed.

## Setup (Mushi Cloud, no code)

1. At **id.atlassian.com → Security → API tokens**, create an API token.
2. In the Mushi console: open the **Integrations** page, find **Jira**, and
   enter your Jira base URL (e.g. `https://acme.atlassian.net`), the
   Atlassian email that owns the token, the token, and the project key
   (e.g. `BUG`).
3. Click **Save**, then **Test connection**.

Mushi opens and resolves the Jira issues itself; you do not need the npm package.

## Self-hosted plugin

[`@mushi-mushi/plugin-jira`](https://www.npmjs.com/package/@mushi-mushi/plugin-jira)
is a library for doing the same from your own server with Jira OAuth 2.0
(3LO): `buildAuthorizeUrl`, `exchangeCode`, `refreshTokens` and
`createJiraPluginHandler`. See its README for the code. The console's
Marketplace has no Jira listing, so it only receives events from a Mushi
server you run yourself, once you add a `plugin_registry` row for it.

| Event | Action |
| --- | --- |
| `report.created` | Create a Jira issue under `jiraProjectKey`, labelled with category and severity |
| `report.status_changed` | Run the Jira transition from `statusToTransition` (defaults: pending/classified/grouped → To Do, fixing → In Progress, fixed/dismissed → Done) |
| `fix.applied` | Comment with the fix PR link or summary |

The report → issue mapping is kept in memory, so after a restart status
changes and fix comments for older reports are skipped.
