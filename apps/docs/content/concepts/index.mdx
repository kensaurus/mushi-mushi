# Concepts

{CONCEPTS_INDEX_LEDE}

The loop in plain terms:

1. **Capture**: users report what felt broken (by shaking the phone, tapping, or using the widget), and Mushi adds a screenshot and what they were doing.
2. **Plain read**: how serious it is, what kind of problem it is and the likely cause, in everyday English.
3. **Connect**: similar reports merge into one item, and the parts of the app that break most often stand out.
4. **Fix**: optionally, an AI agent drafts the fix as a pull request (a proposed code change); you merge it, edit it or ignore it.
5. **Verify**: an automated replay checks the fix before you ship it.
6. **Remember**: past fixes become rules your editor sees on the next pull request.
