# Mobile

Pick the SDK that matches how you ship the app. React Native and Capacitor are
published on npm and set up by `npx mushi-mushi`.

  
  

The native SDKs are previews: they are not on CocoaPods, Maven Central or
pub.dev yet, so each page shows how to install from the GitHub repository.
