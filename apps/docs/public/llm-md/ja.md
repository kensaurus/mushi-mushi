# Mushi Mushi とは

Mushi Mushi は、アプリに「問題を報告」ボタンを追加し、届いた不具合の原因と直し方を AI が説明するオープンソースのツールです。

Lovable、Bolt、Cursor、Claude Code などの AI でアプリを作り、公開している個人開発者のために作りました。困ったユーザーの多くは、何も言わずに離れていきます。Mushi Mushi は、声を上げてくれた人の報告を逃さず、直すところまでを短くします。

  このページと[特定商取引法に基づく表記](/legal/tokushoho)以外のドキュメント、管理画面、AI による診断は、現在すべて英語です。
  報告ボタン（ウィジェット）は日本語で表示されます。

## まず無料で試す：公開中のサイトをチェック

登録は不要です。公開中のアプリの URL を貼ると、リンク切れ、表示されない画像、開けないページ、テンプレートのままのタイトル、読み込み時のエラーを調べます。

[公開中のサイトを無料でチェックする](/check?src=ja-page)

チェックの画面は英語ですが、指摘は短い文です。そのまま Lovable や Cursor のチャットに貼って、修正を頼めます。

## できること

1. **報告ボタンを追加する。** アプリの隅に小さなボタンが表示されます。使っている人は、ひと言書いて送るだけです。画面のスクリーンショット、開いていたページ、直前の操作が一緒に届きます。
2. **原因を説明する。** 届いた報告ごとに、AI が「何が起きたか」「どのくらい深刻か」「考えられる原因」を平易な英語で書きます。同じ不具合の報告は 1 件にまとめます。
3. **直し方を渡す。** 報告ごとに、修正用のプロンプトが付きます。Lovable や Bolt にはそのまま貼り付け、Cursor や Claude Code からは直接読み込めます。

AI の診断は間違うことがあります。変更内容は、公開する前に必ず確認してください。

## 報告ボタンは日本語で表示されます

ボタンと報告画面は、使う人のブラウザの言語に合わせて表示されます。日本語のブラウザでは、設定なしで日本語になります。対応している言語は、日本語、英語、スペイン語、タイ語、中国語（簡体字）です。それ以外の言語では英語で表示されます。

管理画面（コンソール）と AI の診断は、現在は英語のみです。

## 始め方：Lovable・Bolt の場合

ターミナルは使いません。5 分ほどで終わります。

1. **無料登録して、スクリプトタグをコピーする。** [無料登録](https://kensaur.us/mushi-mushi/admin/signup?src=ja-page)してプロジェクトを作ります。サイドバーの **Set up** を開き、**Install widget** タブの **Script tag** を選びます。プロジェクト ID は最初から入っています。キーが `YOUR_SDK_KEY` のままなら、**Generate API key** を押すと本物のキーが入ります。
2. **Lovable または Bolt のチャットに送る。** 次の文に続けて、コピーした自分のタグをそのまま貼ってください。

   ```text
   Add this script tag inside the <head> of index.html exactly as written, and change nothing else:
   ```

3. **公開して、テスト報告を送る。** 公開したサイトを開き、報告ボタンを押して「テストです」と送ります。数秒で管理画面に届き、深刻度と考えられる原因が表示されます。
4. **届いた報告を直す。** 管理画面で報告を開き、**Copy fix prompt** を押して、Lovable または Bolt のチャットに貼ります。

画面つきの手順は [Lovable・Bolt 向けクイックスタート（英語）](/quickstart/lovable-bolt)にあります。

## 始め方：Cursor・Claude Code の場合

アプリのフォルダで次のコマンドを実行します。

```bash
npx mushi-mushi
```

ブラウザでサインインし、SDK のインストールと設定の書き込みまで自動で行います。詳しくは[クイックスタート（英語）](/quickstart)をご覧ください。
